# Nexa font files

Put your licensed Nexa files here (from Fontfabric). `.woff2` is preferred; `.otf` also works.

| Weight | File name |
| --- | --- |
| Light (300) | `Nexa-Light.woff2` or `Nexa-Light.otf` |
| Regular (400) | `Nexa-Regular.woff2` or `Nexa-Regular.otf` |
| Bold (700) | `Nexa-Bold.woff2` or `Nexa-Bold.otf` |
| Extra Bold (800) | `Nexa-XBold.woff2` or `Nexa-XBold.otf` |

Rename the files to match if yours are named differently. Missing weights fall back to the nearest available one.
These files are served to every visitor, so check that your licence covers web embedding.
